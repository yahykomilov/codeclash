# 🎨 Yahyo — Frontend / web

Твоя зона: `packages/web`. Каркас всех экранов уже стоит и работает в демо-режиме.
Задача — довести до «вау» и мобильной надёжности. Судьи смотрят на живое, работающее демо.

## Что уже есть
- Экраны: `Home`, `Login`, `Register`, `Join`, `Play` (игрок), `Host` (большой экран).
- i18n RU/UZ/EN (`src/i18n/locales/*.json`), переключатель языка в шапке.
- Плитки ответов в стиле Kahoot, таймер, лидерборд, подиум.

## Твои задачи (по приоритету)
1. **Мобильный адаптив** экрана игрока (`Play.tsx`) — плитки на весь экран, крупные, удобно тапать одной рукой. Это то, что увидят на телефонах судьи.
2. **QR-код на PIN** в лобби ведущего (`Host.tsx`, фаза `lobby`) — чтобы заходили сканом, а не набором. Пакет `qrcode.react`, ссылка вида `/join` (PIN можно допрокинуть в query).
3. **Анимации и звук**: обратный отсчёт вопроса, «пульс» при ожидании, звук правильного/неправильного ответа, звук тиканья таймера. Ассеты — в `public/`.
4. **Реконнект игрока**: если телефон потерял связь — не выкидывать из игры (см. с Otabek событие реконнекта по `gameId` в `localStorage`).
5. **Полировка**: экран результата (`Play`), подиум (`Host`) — сделать эффектными (конфетти на 1 месте, счётчик очков «набегает»).
6. **Пустые/крайние состояния**: сеть отвалилась, host закрыл игру, неверный PIN — понятные сообщения (ключи уже есть в `errors.*`).

## Правила
- Новые тексты — только через i18n (добавляй ключ во все три `locales/*.json`).
- Контракты сокетов и типы бери из `@codeclash/common` — **не меняй их** без Otabek.
- Проверяй на реальном телефоне в одной сети (Vite: `--host`, зайти по IP ПК).

## Запуск

npm run dev        # из корня; фронт на :5173

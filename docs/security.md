# 🛡️ Security — модель угроз и статус (STRIDE)

Провели STRIDE-аудит всего кода (сокет-сервер, React-клиент, общий пакет, конфиги) — чтобы на защите
у нас «не нашли слабостей». Ниже: что уже крепко, что нашли и что закрыли.

## ✅ Уже крепко (проверено, показываем смело)
- **Правильные ответы не утекают клиенту до разбора** — `PublicQuestion` не содержит `correct`, он уходит только в `REVEAL`. (Ключевая проверка для квиза — пройдена.)
- **Роль ведущего не подделать** — `socket.data.role` ставит только сервер; игрок не может слать host-события в чужую игру.
- **XSS через ник не проходит** — всё рендерится через JSX (React авто-экранирует), `dangerouslySetInnerHTML`/`innerHTML`/`eval` в проекте нет.
- **Секреты не в гите** — `.env` в `.gitignore`, в бандле только публичный `anon`-ключ Supabase, `service_role` нигде нет.
- **CORS не wildcard** — один origin из `CLIENT_ORIGIN`.

## 🔧 Найдено и ЗАКРЫТО (внедрено в этой ветке)
| Угроза (STRIDE) | Что было | Фикс |
|---|---|---|
| DoS: брутфорс PIN, флуд join/create/answer | Нет rate-limit нигде | **Token-bucket rate-limiter** на сокет-события (join по IP, create/answer по сокету) + `express-rate-limit` на HTTP |
| Tampering: сырой `answers` (гигантский массив, дробные/вне диапазона) | Только `Array.isArray` | **zod-схема** `answersSchema` (целые, 1–10, в диапазоне) + дедуп + проверка границ по вопросу |
| DoS: огромный payload | Дефолт 1 МБ | `maxHttpBufferSize: 8 КБ` + `connectTimeout` |
| Elevation: кик — косметика (игрок остаётся в комнате, видит правильные ответы) | `removePlayer` не выкидывал из room | **Enforced kick**: `socketsLeave(pin)` + проверка членства перед emit |
| Spoofing/визуальный: невидимые/RTL/markup-ники | Ник — любые символы 2–20 | **Строгий regex** `^[\p{L}\p{N} _.-]{2,20}$` + дедуп ников в игре |
| Tampering: предсказуемый PIN (`Math.random`) | Не крипто | **`crypto.randomInt`** |
| DoS: флуд создания игр, осиротевшие игры | Без лимитов, finished-игры не удалялись | Лимит игр/сокет + очистка при финише/реконнекте + `maxHttpBufferSize` |
| Info: локаль-инъекция в индексацию | `payload.locale` как есть | `sanitizeLocale()` — только известные локали |
| Security-заголовки | Нет | **helmet** (+ убран `x-powered-by`) |

## 📋 Для XOB (настройка окружения — критично)
- **Включить RLS на всех таблицах Supabase.** Публичный `anon`-ключ в бандле безопасен ТОЛЬКО при включённом RLS — иначе это полный доступ к данным.
- **(Опционально, если время)** серверная аутентификация ведущего: прокидывать Supabase JWT в `io(url,{auth:{token}})` и проверять `io.use()` через `supabase.auth.getUser(token)`. Сейчас гейт «войди, чтобы хостить» — клиентский; для этой игры хостинг не чувствителен, но по вебсокету обходится. См. `docs/xob-integration/`.

## 🧪 Живой security + E2E тест
`packages/server/scripts/e2e.mjs` (node + socket.io-client) прогоняет полный цикл игры и атаки — **10/10 пройдено**:
реджект markup-ника, дедуп ников, **правильные ответы не утекают до разбора**, сервер жив после мусорных
payload, rate-limit ловит флуд join. Запуск: поднять сервер → `node packages/server/scripts/e2e.mjs`.

> Strix (autonomous pentester) на этой машине не запускается — требует Docker/WSL2, которого нет.
> Заменён ручным STRIDE-аудитом + автоматическим E2E security-тестом выше.

## Вывод
Чувствительных дыр (утечка ответов, XSS, подмена ведущего, утечка секретов) — нет. Внедрены анти-чит/анти-DoS
меры промышленного уровня для хакатон-проекта. Осознанный компромисс — демо-режим без Supabase отключает
серверную auth (by design, чтобы демо игралось без ключей); с ключами включается полноценный вход.

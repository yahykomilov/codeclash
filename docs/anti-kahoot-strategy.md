# 🥊 Как CodeClash контрит Kahoot (стратегия победы)

Мы не «ещё один клон». Каждая фича бьёт по конкретной задокументированной слабости Kahoot,
которую видит **большинство** игроков. Ядро питча: называем боль Kahoot → показываем контру вживую.

Слабости — из реальных жалоб учителей/игроков (форумы Kahoot с топ-голосованными запросами,
статьи про читы/ботов, accessibility-обзоры). Не выдумано.

---

## 🎯 ТОП-5 «kill shots» — статус реализации

| # | Слабость Kahoot | Наша контра | Статус |
|---|-----------------|-------------|--------|
| 1 | **Очки за скорость** наказывают вдумчивых-но-правильных (жалоба №1). | Тумблер режима очков у ведущего: **«Честный»** (равные очки всем правильным) / «Сбалансированный» / «Классика». В демо: «двое правы → Kahoot 950/500, у нас 1000/1000». | ✅ **Готово** (`scoring.ts`, выбор на экране ведущего) |
| 2 | **Читерство**: боты, флуд по PIN, гуглёж (вопрос только на экране ведущего), спам-ники. | (а) полный вопрос+ответы на телефоне; (б) **перемешивание позиций ответов** на каждом вопросе; (в) **rate-limit** подключений/ответов + **санитайзер ников** (реджект markup/невидимых) + дедуп + кик реально выкидывает. | ✅ **Готово** (сервер: rate-limit, shuffle, validation, enforced kick) |
| 3 | **Не учит** — нет «почему» после ответа. | **Объяснение на каждый вопрос**, авто-показ на разборе у ведущего и у игрока. | ✅ **Готово** (40 вопросов × 3 языка = 120 объяснений) |
| 4 | **Дисконнект = теряешь всё**, нет реконнекта. | Восстановление сессии при обрыве: rooms/очки не теряются в окне; grace-период вместо мгновенного убийства игры. | 🟡 **База готова** (`connectionStateRecovery` 60с + grace 45с). Полный token-reconnect (закрытие вкладки) → таск Otabek |
| 5 | **Только цвет на плитках**, нет доступности, англо-центричность. | Плитки = форма + текст (не только цвет); **озвучка вопроса** (SpeechSynthesis); **RU/UZ/EN**. | ✅ **Готово** (форма+текст, read-aloud, i18n) |

## 🔁 Вторичные контры
- **«Всегда одни выигрывают»** → ✅ **камбэк-бонус**: отстающая половина при правильном ответе получает +30% (видно бейдж «🚀 Камбэк-бонус»). Динамика возврата в игру.
- **Пейволл** (free: 10 игроков) → ✅ **без лимита** (технический потолок 200/комнату), все типы бесплатно, выведено на экран.
- **Публичный лидерборд = стресс** → ✅ **приватный «chill» режим**: тумблер у ведущего, игроки видят только свой ранг, без публичного давления.
- **Нет паузы, ведущий = точка отказа** → ✅ **пауза/продолжить** у ведущего (замораживает таймер для всех, оверлей «⏸ Пауза»). Kahoot так не умеет.

## 🛡️ Кибербезопасность — проверено
Полный STRIDE-аудит + внедрение (helmet, rate-limit, крипто-PIN, строгая валидация, enforced kick,
санитайзер ников, `maxHttpBufferSize`). Детали и таблица угроз → `docs/security.md`.
**Живой E2E + security-тест: 10/10 проверок пройдено** (`packages/server/scripts/e2e.mjs`), в т.ч.
подтверждено, что правильные ответы НЕ утекают до разбора и сервер не падает от мусорных payload.

## Демо-хребет
**#1 честный скоринг → #2 анти-чит (шафл + rate-limit) → #3 объяснения → #5 озвучка/i18n → #4 устойчивость к обрыву.**
Каждый пункт = видимый момент «Kahoot так не умеет».

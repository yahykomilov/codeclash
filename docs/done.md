# ✅ Что уже готово (стартовый каркас)

Собран рабочий скелет проекта — от него команда пилит свои части. Всё написано с нуля.

## Общее
- Монорепо на npm workspaces: `packages/common`, `packages/server`, `packages/web`.
- Единый запуск: `npm install` → `npm run dev` (сервер :3001 + фронт :5173).
- `.env.example` с переменными (сервер, Vite, Supabase).
- `.gitignore`, `README.md`.

## common (контракты)
- Типы: `Question`, `Quiz`, `Player`, `PublicQuestion`, `LeaderboardEntry`, `PlayerResult`, локали.
- События сокетов `C2S` / `S2C` в одном месте (и сервер, и фронт импортят отсюда).
- Валидаторы (zod): ник, PIN, email, пароль.
- Скоринг: очки за скорость правильного ответа + бонус за серию; проверка мульти-ответов.
- **Банк вопросов: 40 штук** — по 10 на HTML / CSS / JS / React, три языка (ru/uz/en), разные сложности, есть мульти-выбор.

## server (игровой движок)
- Socket.io: комнаты по 6-значному PIN, host + игроки в одной комнате.
- Полный игровой цикл: лобби → вопрос (таймер) → сбор ответов → разбор (правильный + распределение голосов) → лидерборд → следующий → подиум.
- Начисление очков на сервере (авторитетно), серии (streak).
- Обработка: игрок вышел, host вышел (игра закрывается), кик игрока, ранний конец вопроса когда все ответили.
- `GET /health` для проверки живости.

## web (клиент)
- Роутинг: `/` (два входа), `/login`, `/register`, `/join`, `/play`, `/host`.
- Главная: две крупные кнопки — «Участник» и «Создать лобби».
- Регистрация и вход (email/пароль) + кнопка **Google** через Supabase.
- Демо-режим: если ключи Supabase не заданы — приложение работает, авторизация мягко отключена (не блокирует показ).
- Экран игрока: плитки ответов (как в Kahoot), таймер, результат, финальное место.
- Экран ведущего (большой экран): PIN, живой список игроков, вопрос + счётчик ответивших, разбор с барами голосов, лидерборд, подиум.
- i18n RU / UZ / EN с переключателем языка в шапке; сервер шлёт ключи ошибок — клиент их переводит.

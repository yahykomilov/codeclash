## Mahsulot 1 jumlada

**CodeClash** — bu jonli (realtime) ko'p o'yinchili IT-viktorina, Kahoot uslubida. Mavzu — dasturlash: HTML, CSS, JavaScript, React. Boshlovchi katta ekranda savol chiqaradi, o'yinchilar telefonidan javob beradi, kim tez va to'g'ri javob bersa — ko'proq ochko oladi.

## Nega bu yutadi (buni yodda tut, hamma joyda takrorlaymiz)

1. **Realtime haqiqatan ishlaydi.** Ko'p jamoalarda jonli ulanish uziladi — bizda uzilmaydi. Bu bizning asosiy kuchimiz.
2. **Bitta aniq fokus.** Biz 10 ta yarim ishlaydigan narsa emas, bitta to'liq ishlaydigan o'yin qildik.
3. **Tushunarli foyda.** O'qituvchi 30 soniyada test o'tkazadi, dars qiziqarli bo'ladi.
4. **"Bor edi / bo'ldi" (было/стало).** Oldin: zerikarli test qog'ozda. Endi: butun sinf telefondan jonli musobaqa qiladi.

# 📋 Таски команды — CodeClash

Хакатон, время ограничено. У каждого своя зона, детали — в папке `docs/<имя>/`.
Правило: один чёткий фокус, доводим до конца, а не пять фич наполовину.

## Yahyo — Frontend / web  → [`docs/yahyo-frontend/`](yahyo-frontend/README.md)
Довести UI до «вау»: адаптив под телефон, анимации, звук, QR-код с PIN на экране ведущего,
реконнект игрока, полировка экранов результата/подиума. Каркас уже стоит в `packages/web`.

## Otabek — Backend  → [`docs/otabek-backend/`](otabek-backend/README.md)
Укрепить игровой движок: реконнект host/игрока по gameId, сохранение результатов игры в Supabase,
(стретч) сохранение своих квизов от ведущего. Каркас — `packages/server`.

## XOB — Integration & Auth  → [`docs/xob-integration/`](xob-integration/README.md)
Поднять Supabase-проект, включить **Google-вход** (пошагово), вставить ключи, связать фронт+сервер,
задеплоить (фронт → Vercel, сервер → Render/Railway), прогнать сквозной E2E-тест на нескольких телефонах.

## Abdulaziz — Video & Presentation  → [`docs/abdulaziz-presentation/`](abdulaziz-presentation/README.md)
Демо-видео (2–2.5 мин, покадрово), презентация (9 слайдов), питч на 60 сек — материалы уже готовы, снять и собрать.

---

### Порядок сборки (чтобы не блокировать друг друга)
1. **Все:** `npm install` в корне, `npm run dev` — убедиться, что демо-режим играется локально.
2. **XOB:** поднимает Supabase → кидает `VITE_SUPABASE_URL` / `VITE_SUPABASE_ANON_KEY` в общий `.env` → включает Google.
3. **Yahyo / Otabek:** пилят свои части параллельно (контракты в `packages/common` уже зафиксированы — не ломаем их без согласования).
4. **XOB:** деплой, общий прогон.
5. **Abdulaziz:** записывает демо по готовому продукту.

### Не трогать без согласования
`packages/common` — это контракт между фронтом и сервером (события, типы). Меняем только все вместе.
